# 开始使用

这个文档站可以作为你的个人开发知识库。建议按「主题」组织长期知识，按「日期」或「项目」记录阶段性经验。

## 推荐结构

- `guide/`：知识库说明、写作规范、维护方式。
- `notes/`：技术笔记、学习记录、问题排查。
- `projects/`：项目复盘、架构决策、上线记录。
- `snippets/`：常用命令、代码片段、配置模板。

## 写作原则

- 标题直接描述问题或结论。
- 优先写可执行步骤，再补充背景。
- 对容易遗忘的判断写清楚上下文和取舍。
- 保留命令、版本、错误信息和验证方式。

## 常用命令

```bash
npm run dev
npm run build
npm run preview
```
