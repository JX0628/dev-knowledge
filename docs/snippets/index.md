# 代码片段

这里保存可以直接复制使用的小段代码、脚本和工具函数。

## 什么时候放这里

- 某段代码以后还会复用。
- 写法容易忘，但不值得单独写一篇长文。
- 需要保留一个最小可运行示例。

## 推荐格式

```md
# 片段名称

## 用途

## 代码

## 注意事项
```
